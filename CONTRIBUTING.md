# Mitwirken

1. Forken Sie das Repository und erstellen Sie einen eigenen Branch.
2. Halten Sie Änderungen klein, nachvollziehbar und klar beschrieben.
3. Testen Sie unter Windows mit Node.js 22 oder neuer mindestens die Syntaxprüfung (`npm run prepare`).
4. Führen Sie bei Änderungen an der Suche zusätzlich Index- und Suchtests aus.
5. Reichen Sie keine persönlichen Daten, echten Systeme, IP-Adressen oder Zugangsdaten ein.
6. Committen Sie keine Modelle, Indexdateien, Cache- oder `node_modules`-Dateien.
7. Ergänzen Sie Pull Requests um eine kurze Beschreibung und das Testergebnis.
