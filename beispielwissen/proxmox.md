# Erfundenes Virtualisierungslabor

Das vollständig erfundene Labor enthält zwei virtuelle Systeme:

- **Demo-VM Alpha** stellt eine kleine Übungsanwendung bereit.
- **Demo-Container Beta** sammelt ausschließlich künstlich erzeugte Testwerte.

Beide Systeme verwenden nur beschreibende Fantasienamen. Es sind keine Adressen, Kennungen oder Daten realer Systeme enthalten.
