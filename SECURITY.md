# Sicherheit

Schreiben Sie keine Zugangsdaten oder vertraulichen Details in öffentliche Issues. Melden Sie Sicherheitsprobleme möglichst über GitHubs private Sicherheitsmeldung. Falls diese Funktion nicht verfügbar ist, eröffnen Sie ein neutrales Issue ohne sensible Details.

Dieses privat gepflegte Beispielprojekt bietet keine feste Reaktionszeit oder Supportgarantie.
